# 独立开发者的项目收纳盒

一个帮助独立开发者从更高视角看待自己项目的工具。按照项目已经实现的商业结果，将你的项目归入不同的类别。

## 五个类别

| 类别 | 说明 |
|------|------|
| 完全免费的项目 | 没有形成任何直接收入，用户可以免费使用 |
| 能获得一次性收益的项目 | Hackathon 奖金、定制项目等 |
| 能获得少量用户长期订阅的项目 | 少量用户持续付费订阅 |
| 能获得大量用户付费的项目 | 大量用户一次性付费（如 Steam 游戏、课程） |
| 能获得大量用户长期订阅的项目 | 大量用户持续付费订阅 |

## 功能

- 添加、编辑、删除项目
- 项目分类管理
- 项目间移动分类
- 项目链接和 GitHub 链接
- 导出为 CSV 或 HTML
- 数据本地存储（localStorage）
- 暗色模式支持
- 响应式设计

## 技术栈

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS

## 开始使用

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 代码检查
npm run lint
```
